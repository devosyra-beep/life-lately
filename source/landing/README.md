# Fonte da landing

Origem: `life-s-luxe-ledger-main.zip`, enviado nesta conversa.
Este TSX e o CSS de referência preservam a página original com a nova chamada e o link `/app/`.

A versão publicada foi adaptada para HTML/CSS estáticos em `../../index.html` e `../../assets/landing/landing.css`, sem React ou Tailwind no navegador. Assim, basta publicar a pasta completa no Netlify; não há etapa npm ou servidor de aplicação.

As três fotografias originais estão em `../../assets/landing/`, junto das versões WebP responsivas. A tipografia do projeto continua carregada por Google Fonts, com fontes de sistema como fallback. Nenhum arquivo de fonte é distribuído.

Edite os arquivos estáticos para alterar a versão publicada. Estes dois arquivos de referência não são um segundo projeto executável.
